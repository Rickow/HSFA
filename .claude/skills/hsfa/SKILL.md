# HSFA

1. Lire **`AGENTS.md`** à la racine du dépôt : règles, méthode, acquis, chantiers, organisation. Il fait foi.
2. Puis, selon la tâche : `docs/journal/ETAT-DES-LIEUX.md` (commandes exactes), `docs/journal/INDEX-HANDOFF.md`
   (index du journal), les dernières sections de `docs/journal/HANDOFF.md`, `docs/methodes/` et le rapport du chantier
   concerné dans `docs/rapports/`.
3. Répondre et documenter en **français**.
4. Avant tout commit : vérification d'anonymat (`AGENTS.md` §2) ; avant tout push : `git log origin/main..HEAD`.
5. Après une découverte durable : mettre à jour le journal **et** `AGENTS.md` (§7 de ce fichier).
