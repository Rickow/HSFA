# FBNeo libretro core "HSFA"

**Français : [README.fr.md](README.fr.md)**

Patches against [libretro/FBNeo](https://github.com/libretro/FBNeo), commit `af5d3f3`.

- How the core works: [docs/architecture/coeur-fbneo.md](../../docs/architecture/coeur-fbneo.md).
- One sheet per patch (problem, solution, rejected alternatives, files, how to turn it off):
  [docs/architecture/coeur-fbneo-patchs.md](../../docs/architecture/coeur-fbneo-patchs.md). The sheet carries the number
  of the "#" column.
- Game archives and notices: [tools/fbneo-hsfa](../../tools/fbneo-hsfa/README.md).
- **Licence**: the cores built with these patches are FinalBurn Neo and follow its licence, copied word for word
  into [LICENSE-FBNeo.txt](LICENSE-FBNeo.txt) (no sale, no donations; sources of the changes = these patches). Notices
  of stb_vorbis (patch `0004`) and of the BSD-3 QSound HLE (patch `0001`): [NOTICE.md](../../NOTICE.md). To be included
  with any core archive.
