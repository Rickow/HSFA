Constructeur HSFA -- de vos disques aux jeux HSFA, sans rien installer
=======================================================================

Il vous faut :
  - votre image PS2 de Street Fighter Alpha Anthology (USA, SLUS-21317), en .iso ou .chd ;
  - (facultatif) votre ISO PSP de Street Fighter Alpha 3 MAX (Europe, ULES-00235), en .iso ou .chd :
    elle ajoute Upper MAX (Eagle, Maki, Yun, Ingrid) ;
  - environ 3 Go libres (5 Go depuis un .chd), 10 a 20 minutes.
Le constructeur ne contient aucune donnee de jeu : tout est lu sur VOS images.

1. Telecharger
   Dans la release du projet, prenez le zip de votre systeme :
     Windows : hsfa-constructeur-windows-x86_64.zip
     macOS   : hsfa-constructeur-macos-arm64.zip (Apple M1 et suivants) ou macos-x86_64 (Intel)
     Linux   : hsfa-constructeur-linux-x86_64.zip (PC) ou linux-aarch64 (ARM 64 bits)
   Dezippez-le ou vous voulez. Empreintes : SHA256SUMS-constructeur.txt dans la release.

2. Lancer
   Windows : double-clic sur hsfa-constructeur.exe, ou glissez l'image PS2 sur l'exe.
   macOS / Linux : double-clic, ou dans un terminal :
       ./hsfa-constructeur                                  (fenetre)
       ./hsfa-constructeur Anthology.iso --psp MAX.iso      (sans fenetre)
   Dans la fenetre : choisissez l'image PS2, l'ISO PSP si vous l'avez, le dossier de sortie, puis « Construire ».

3. Avertissements (normaux : l'executable n'est pas signe)
   Windows : « Windows a protege votre ordinateur » (SmartScreen) -> « Informations complementaires » ->
     « Executer quand meme ». Un antivirus peut aussi se mefier des executables de ce type (PyInstaller) :
     verifiez l'empreinte SHA-256 si vous avez un doute.
   macOS : « impossible d'ouvrir … developpeur non identifie » -> Reglages Systeme > Confidentialite et securite >
     « Ouvrir quand meme ». Ou, dans un terminal : xattr -d com.apple.quarantine hsfa-constructeur
   Linux : si le double-clic ne lance rien : chmod +x hsfa-constructeur

4. Ou mettre les zips
   A la fin, le dossier de sortie (par defaut HSFA-sortie, a cote de l'executable) contient archives/ :
     sfa3hsfa.zip (SFA3), sfa3uhsfa.zip (Upper), sfa3hhsfa.zip (Hyper), sfa3umhsfa.zip (Upper MAX, avec l'ISO PSP).
   Copiez-les SANS LES RENOMMER dans le dossier des ROM de RetroArch (ou de votre console), a cote du coeur
   « FinalBurn Neo HSFA » du projet, puis chargez un zip avec ce coeur. Guides : docs/guide/ du depot.
   Le reste du dossier de sortie (cache, travail) peut etre efface ; le garder accelere une reconstruction.

Probleme ? Joignez journal.txt (dossier de sortie) a un ticket du depot (Issues), en francais ou en anglais.
